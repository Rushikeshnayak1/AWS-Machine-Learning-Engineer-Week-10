# Presentation summaries

## Part 1 — Amazon SageMaker Data Wrangler
**Purpose:** Turn interactive data exploration into a reproducible ML preparation flow.

Presentation sequence: importance of input quality → workflow (import, inspect, transform, export) → supported data source access → data profiling → built-in/custom transformations → handling imbalance and data quality → image preparation/PCA → Quick Model → integration and troubleshooting.

## Part 2 — Amazon SageMaker Model Monitor
**Purpose:** Compare production evidence against reference baselines and respond to signs of change.

Presentation sequence: why performance changes after deployment → baselines → schedules/S3/CloudWatch → data-quality signals → prediction quality and ground truth → bias drift → attribution drift/NDCG → alarms and investigation → deciding which monitoring type fits the symptom.

## Part 3 — Amazon SageMaker Clarify and Feature Store
**Purpose:** Investigate fairness/explainability and manage consistent reusable features.

Presentation sequence: responsible AI questions → fairness facets → metrics (class imbalance, DPL and distribution distance) → PDP → Shapley/SHAP → asymmetric Shapley for time series → Feature Groups → online vs. offline feature stores.

**Format:** Each uploaded presentation contains 10 slides. This document summarizes the slides; it is not a record of a live AWS implementation.
