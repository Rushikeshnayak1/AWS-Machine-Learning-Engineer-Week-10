# Learning challenges and how I approached them

These are study-level difficulties and approaches associated with the presentation concepts, not claims about AWS console problems or completed experiments.

| Learning challenge | How I organized the explanation |
|---|---|
| Distinguishing data quality from model quality | Framed the distinction as **input statistics** versus **prediction performance with ground truth**. |
| Separating bias drift from attribution drift | Used the question **group fairness patterns** versus **feature reliance and rankings**. |
| Understanding multiple Clarify bias metrics | Grouped them into representation, label-rate differences and distribution comparisons. |
| Understanding Online vs. Offline Feature Store | Compared low-latency inference with historical training and batch analysis. |
| Connecting individual AWS services | Drew conceptual diagrams that place preparation, explanation, feature reuse and monitoring in one learning workflow. |
