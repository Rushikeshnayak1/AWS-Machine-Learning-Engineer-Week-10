# Week 10 learning reflection

This week helped me connect machine learning topics that are often studied separately. In Part 1, I focused on how the quality and meaning of input data influence training. In Part 2, I learned why production models need monitoring even after strong evaluation results. In Part 3, I explored how bias analysis, prediction explanations and consistent feature management support more dependable ML applications.

My main takeaway is that a machine learning workflow does not end when a model trains successfully. Data, explanations, reused features and production observations all need attention. I found it especially helpful to associate each service with the question it helps answer, rather than memorizing tool names alone.

For future improvement, I want to compare the conceptual explanations with real AWS examples and keep clear records of what I actually tested. These presentations represent my learning and communication work; they are not evidence of deployed SageMaker services.
